# Diversion Skill for Codex

This repository contains a Codex skill for helping users work with **Diversion** version control (`dv`) in a safe, beginner-friendly way.

## What This Skill Does

- Maps plain-English requests to Diversion commands.
- Prefers read-only/safe checks before write actions.
- Explains commands in non-technical language.
- Encourages branch safety and safer undo workflows.
- Helps with commits, branches, history, undo, shelves, collaboration, and workspace actions.

## Main File

- `SKILL.md`: Core skill instructions, safety rules, and command reference.

## Intended Audience

People who are new to version control and want clear guidance while using Diversion.
